AI National Emergency Resource Brain

Project Overview

AI National Emergency Resource Brain is an intelligent emergency response platform that helps citizens quickly find nearby emergency resources such as hospitals, blood donors, ambulances, doctors, and disaster relief services during critical situations.

Features

- Emergency resource discovery
- Nearby hospital and doctor availability
- Blood donor matching
- Real-time emergency alerts
- AI-powered resource recommendations
- Location-based emergency assistance

Technologies Used

- Artificial Intelligence / Machine Learning
- Python
- Database Management System
- Web Technologies (HTML, CSS, JavaScript)
- APIs and Location Services

Setup Instructions

1. Clone the repository.
2. Open the project folder.
3. Run the application using:

python app.py
4. Use the menu to manage emergency resources.
